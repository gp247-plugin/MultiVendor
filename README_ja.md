# MultiVendor — S-Cart 向けマルチベンダー・マーケットプレイス（Free）· MultiVendorPro（Pro）

> 🚀 **Link MultiVendor PRO:** [https://gp247.net/en/product/multi-vendor-pro.html](https://gp247.net/en/product/multi-vendor-pro.html)

## はじめに
MultiVendor は、S-Cart のウェブサイトを **1 つのドメイン上で複数の出店者が販売するマーケットプレイス** に変えます。仕入先・出店者（ベンダー）は同じストアフロントに商品を掲載し、お客様は 1 回の訪問で複数のベンダーの商品を購入できます。マーケットプレイスが代金を受け取り、手数料を差し引いたうえでベンダーへ支払います。本ドキュメントは、マーケットプレイスの開設を検討している **事業者および S-Cart サイトのオーナー** 向けに、プラグインでできること、Free 版で使える機能、Pro 版で追加される機能を説明します。以下の詳細ドキュメントへの入口でもあります。

## プラグインでできること
MultiVendor を使うと、**あなたの 1 つのウェブサイトで複数の出店者が一緒に販売** できます。各出店者は専用のストアページと専用の管理エリアを持ち、自分で商品を登録し、自分の注文を処理します。

お客様はいつもどおりに買い物をします。複数のストアの商品を 1 つのカートに入れて 1 回で支払うと、システムが自動的にストアごとに 1 件ずつ注文を分割します。

お金と権限はあなたが握ります。**マーケットプレイスがお客様から代金を受け取り、手数料を差し引いてから、期間ごとに出店者へ支払います**。誰が出店できるか、どの商品をマーケットプレイスに掲載するかもあなたが決めます。

Pro 版では、出店者が増えてきたときのためのツールが追加されます。出店プラン、注文が返金されたときの資金回収、申し立て、本人確認、レポート、代理店向けの卸売販売です。

### 詳細

## MultiVendor と Multi-Store の違い
どちらのプラグインも「複数のストア」を扱いますが、**まったく異なる 2 つのビジネスモデル** であり、**同じウェブサイトに一緒にインストールすることはできません**（ストアのデータ破損を防ぐため、システムがブロックします）。最初に正しいほうを選んでください：

| 項目 | 🛒 **Multi-Vendor**（本プラグイン） | 🏢 **Multi-Store** |
|---|---|---|
| 商品の所有者 | あなたのマーケットプレイスで販売する **独立した複数の出店者** | **1 人のオーナー** — あなた自身の事業 |
| モデル | EC マーケットプレイス | 同一オーナーによるチェーン店／複数ブランド |
| ドメイン | **1 つのドメインのみ**。各ストアは `/shop/{コード}` のページです | **ストアごとに独自ドメイン** |
| 商品を登録する人 | 各出店者が自分で登録し、マーケットプレイスが審査します | あなたが登録し、どのストアに属するかを選びます |
| お金の流れ | マーケットプレイスがお客様から代金を受け取り、**手数料を差し引き**、期間ごとに出店者へ支払います | 代金は直接あなたの事業に入り、誰とも分配しません |
| 管理画面にログインする人 | 出店者は専用エリア `/vendor_admin` に入り、自分のストアだけを見られます | あなた（Pro 版では各ストアの管理者も） |
| 向いているケース | **他の人を招いて** 販売してもらい、手数料を得たい場合 | **同じ事業** のために複数のウェブサイト／ドメインがほしい場合 |

簡単に言えば、**Multi-Vendor = 多くの出店者のための市場、Multi-Store = あなた自身の複数のストア** です。商品がすべてあなたのもので、複数のドメインが必要なだけであれば、Multi-Store をお使いください：[gp247.net/en/product/multi-store-pro.html](https://gp247.net/en/product/multi-store-pro.html)。

## Free と Pro の比較
**Pro を購入するのは**：マーケットプレイスのオーナーです。出店者やお客様が GP247 に何かを支払うことはなく、アップグレードの案内を目にすることもありません — Free 版では、各 Pro 機能がどこに配置されるかをオーナーにだけ表示し、クリックすると説明ページが開きます。

Free 版は最大 3 出店者まで実際に運用できるマーケットプレイスです。Pro 版は Free 版の **上に追加で** インストールする 2 つ目のプラグインです（`MultiVendorPro`、`MultiVendor` が必要）。インストールすると、ロックされていたすべての入口から実際の画面が開きます — 再インストールもデータ移行も不要で、Pro を削除しても Pro が作成したテーブルはそのまま残ります。

## 動作要件
- `gp247/core` **3.1** と `gp247/shop` がインストールされた S-Cart 3.x。
- MultiStore プラグインとの同時インストールは **できません**（2 つのモデルは互いに排他的です）。
- 一般的な共有ホスティングで動作します：cron、キューワーカー、websocket は不要です。

## コマンドラインでのインストール（CLI、gp247 3.x）
gp247 3.x 以降では、管理画面を開かずに、GP247 ライブラリから **MultiVendor** をダウンロードしてコマンドラインですぐにインストールできます。ウェブサイトのルートフォルダでターミナルを開き、次を実行してください：

```bash
# 1) ウェブサイトごとに 1 回だけ：GP247 ライブラリに接続するための API License（無料）を登録
php artisan gp247:ext-register-license

# 2) ライブラリからプラグインをダウンロードしてインストール
php artisan gp247:ext-install --type=plugin --key=MultiVendor
```

- 手順 1 の前に、`.env` の `APP_URL` がウェブサイトの **実際のドメイン** になっていることを確認してください（`http://localhost` のままにしないでください）。ライセンスはこのドメインに紐付けられます。
- インストールが完了すると、プラグインは **有効化済み** になり、キャッシュも自動で更新されるため、管理画面で追加の操作は必要ありません。
- コマンドは `gp247.json` に宣言された条件（core 3.1、`gp247/shop`、依存プラグイン、MultiStore と同時にインストールしないルール）を自動でチェックします。不足があればコマンドは停止し、何が足りないかを明示します。
- プラグインのフォルダがすでに `app/GP247/Plugins/` にある場合（手動でコピーした、または zip ファイルから展開した場合）、コマンドは再ダウンロードせずに **その場でインストール** します。
- プラグインがすでにインストール済みの場合、コマンドは拒否します。新しいバージョンに更新するには `php artisan gp247:ext-update --type=plugin --key=MultiVendor` を実行してください。
- コマンドの末尾に `--json` を付けると、機械可読な形式で結果を受け取れます（スクリプト／CI 用）。
- 詳細：[拡張機能のインストールガイド](https://gp247.net/en/docs/user-guide-extension/guide-to-installing-the-extension.html)。

## Q&A（よくある質問）
**質問 1：MultiVendor と Multi-Store はどこが違いますか？**

→ Multi-Store = ストアごとに 1 つのドメインで、商品はあなた自身のものです。MultiVendor = 1 つのドメイン上の共通マーケットプレイスで、外部の多くの出店者が登録して販売し、マーケットプレイスが代金を受け取ってから手数料を差し引いて支払います。完全な比較表は [MultiVendor と Multi-Store の違い](#multivendor-と-multi-store-の違い) の項目にあります。2 つのプラグインは同時にインストールできません。

**質問 2：出店者は自分のウェブサイトやドメインを持てますか？**

→ いいえ。すべてのストアはマーケットプレイスのドメイン上にあり、`/shop/{ストアコード}` のパスでアクセスします。

**質問 3：お客様の代金は誰が受け取りますか？**

→ マーケットプレイスが受け取ります。出店者は決済ゲートウェイのキーを入力しません。マーケットプレイスは手数料を差し引いたうえで、期間ごとに出店者へ支払います（詳細ガイドの「支払いプロセス」の項目をご覧ください）。

**質問 4：Free 版で始めて後から Pro 版にすると、何か失われますか？**

→ いいえ。Pro 版は Free 版の上に追加でインストールします。ストア、出店者、注文、支払台帳はそのまま残ります。Free 版で設定していた個別の手数料率も保存されており、Pro 版をインストールした時点ですぐに有効になります。

**質問 5：出店者やお客様が販売価格やアップグレードボタンを目にすることはありますか？**

→ いいえ。Pro の項目が見えるのはマーケットプレイスの管理者だけです。出店者が Pro 機能に触れた場合は、その機能がマーケットプレイスの Pro 版に属しており、マーケットプレイスに依頼するよう案内されるだけです。

**質問 6：決める前に試してみたい場合はどこで見られますか？**

→ 公開デモのマーケットプレイス：https://m-vendor.s-cart.org — 実際のお客様と同じように、ストアページ、ストア一覧、購入フローを開いてみてください。
